<ins>**Low-Level UEFI Firmware Development Portfolio**</ins>

This repository tracks my progress of learning and building my own custom UEFI applications using EDK2 on Linux (Ubuntu Based). 
Optimized for low-level diagnostics, register verification, and firmware development exploration.

<br>

<ins>**Core Engineering Focus**</ins>

Bare-Metal Development: 
Bypassing OS kernels and runtime libraries (glibc) to write freestanding C code.

Hardware Interfacing: 
Interacting directly with CPU registers, system memory topologies, and firmware tables.

Execution Phase: 
Operating entirely within the pre-OS execution environment.

<br>

<ins>**Development Environment & Toolchain Host**<ins> 

OS: Linux - Zorin OS / Ubuntu Core Base

Framework: TianoCore EDK2 (EFI Development Kit II)

Target Architecture: X64 (64-bit Long Mode)

Compiler: GCC (GNU Compiler Collection)

Simulation: QEMU Virtualization with Open Virtual Machine Firmware (OVMF)
