This is a simple Arithmetic UEFI application where you are required to enter two different inputs and the output would be the sum, difference, product and quotient.
Since the UEFI firmware cannot display the actual integers directly in the display, this application converts the ASCII keyboard inputs into integers so the user can see what they had put as an input on the display.
Then the calculations of sum, difference, product and quotient are given as outputs and then the user will be prompted to press any key to exit back to the shell. 
I have also tested the text attributes which was simply changing the text color and the background color of that particular text.
